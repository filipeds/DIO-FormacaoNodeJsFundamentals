# 🛒 Carrinho de Compras Shopee

> Carrinho de compras inspirado na Shopee, controlado por menu no terminal: lista produtos, adiciona, remove, altera quantidades e calcula totais com controle de estoque.

Desafio de projeto da trilha **Formação Node.js Fundamentals** da [DIO](https://www.dio.me/).

## Sobre esta branch

Esta branch (`feat/carrinho-compras-shopee-nodejs`) contém **apenas** este desafio, na pasta [`carrinho-compras-shopee-nodejs/`](carrinho-compras-shopee-nodejs). Ele foi integrado à `main` pelo [PR #7](https://github.com/filipeds/DIO-FormacaoNodeJsFundamentals/pull/7).

## Destaques

- Catálogo com 6 produtos, preço e estoque
- Estoque reservado ao adicionar e devolvido ao remover
- Erros tratados sem derrubar o programa; lógica coberta por testes

## Tecnologias

- Node.js
- JavaScript (CommonJS)
- Jest

## Como rodar

```bash
cd carrinho-compras-shopee-nodejs
npm install
npm start
```

Testes:

```bash
npm test
```

Mais detalhes, regras e rotas no [README do projeto](carrinho-compras-shopee-nodejs/README.md).
