# 🏁 Simulador de Corridas Mario Kart

> Simulador de corrida de Mario Kart no terminal: dois personagens sorteados disputam 5 rodadas de reta, curva e confronto, com dados, casco, bomba e turbo.

Desafio de projeto da trilha **Formação Node.js Fundamentals** da [DIO](https://www.dio.me/).

## Sobre esta branch

Esta branch (`feat/simulador-corridas-mario-kart`) contém **apenas** este desafio, na pasta [`mario-kart-race-simulator/`](mario-kart-race-simulator). Ele foi integrado à `main` pelo [PR #6](https://github.com/filipeds/DIO-FormacaoNodeJsFundamentals/pull/6).

## Destaques

- 6 personagens sorteáveis e código orientado a objetos (`Character`, `Race`)
- Mecânica bônus do `extras.md`: casco (-1), bomba (-2) e turbo (+1)
- Pontuação nunca negativa e testes automatizados

## Tecnologias

- Node.js
- JavaScript (CommonJS)
- Jest

## Como rodar

```bash
cd mario-kart-race-simulator
npm install
npm start
```

Testes:

```bash
npm test
```

Mais detalhes, regras e rotas no [README do projeto](mario-kart-race-simulator/README.md).
